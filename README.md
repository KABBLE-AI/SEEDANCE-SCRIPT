# SEEDANCE-SCRIPT

## 医疗设备提示词

原有 `generate_medical_device_prompts.py` 和 `medical_device_prompts.csv` 用于医疗设备提示词生成与整理。

## 每日点菜

新增 [周记每日点菜](daily-menu/README.md)：基于菜单截图制作的独立中文交互页面，支持选菜计价、大小份、按日期保存、历史再点、复制清单和备份。

下载 [`daily-menu/index.html`](daily-menu/index.html)，用浏览器直接打开，无需安装依赖。GitHub 的文件预览只展示源代码；下载后的 HTML 才是可交互页面。
