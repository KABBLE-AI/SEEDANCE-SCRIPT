# 周记 · 每日点菜

根据「净香园周记把子肉 · 千禧城」菜单截图制作的中文点菜小本。20 道菜，适配手机和桌面；奶油白与鼠尾草绿配色，内嵌矢量插画，无外部图片、字体、脚本或运行时依赖。

## 使用

下载 **`index.html`**，用现代浏览器直接打开即可。这个文件已包含全部样式、菜单数据和交互代码，不需要安装 Node.js，也不需要服务器。GitHub 的文件预览只展示源代码，请下载后用浏览器打开。也可以把它放在任意静态网站服务中。

1. 选择日期及午餐 / 晚餐。
2. 按分类或菜名查找，选择大小份，再用 `＋ / −` 调整数量。
3. 填写口味备注，点击「保存本次点单」。
4. 复制或下载点单清单，自行发给店家。
5. 从「点单记录」查看历史，或把之前的菜加入当前餐次。

每个日期的午餐、晚餐草稿相互独立。每餐保留一份已保存记录，再次保存更新该餐记录。金额以整数分计算，大小份分开计价；每个菜品规格最多 99 件。历史点单保存当时的菜名、单价与备注；再次加入时使用当前菜单价。

「菜单设置」可修改菜名、单价，或恢复截图菜单。截图日期为 2026-06-24，其中宫保鸡丁按改价后的 **小份 8 元 / 大份 16 元**录入；两个“素菜”分别标注为“素菜（份装）”与“素菜（单个）”；“辣椒 / 茄子”拆成两道各 3 元的菜。

## 数据与备份

- 菜单改动、草稿、记录保存在当前浏览器的 `localStorage`，不会自动跨设备同步。
- 「点单记录 → 导出备份 / 导入备份」可迁移全部数据。导入会先验证文件并确认替换；非法文件不会覆盖记录。
- 清除浏览器数据、使用无痕模式或更换文件位置，可能使原记录不可用。长期使用建议固定页面地址并定期导出备份；不同浏览器对本地 `file://` 的持久存储支持也有差异。
- 无法持久保存时页面会显示提示，仍可复制或下载清单；复制权限不可用时提供选中文本手动复制。
- 这是个人点菜与记账页面，**没有接入商家收单、支付、配送或账户服务**。「保存」仅保存个人记录，不代表商家接单。

## 开发

Node.js 18 或更新版本即可，无需 `npm install`。

```bash
cd daily-menu
npm run build
npm test
```

- `src/menu-data.js`：原始菜单与价格（金额单位：分）。
- `src/core.js`：计价、日期、订单快照、备份验证等纯逻辑。
- `src/app.js`：页面交互、本地持久化与导入导出。
- `src/styles.css`、`src/template.html`：响应式布局与页面结构。
- `build.mjs`：生成可直接打开的单文件 `index.html`。
- `tests/core.test.cjs`：菜单价格、混合计价、历史价格快照、日期隔离、备份损坏、边界数量及构建完整性测试。

生成后的 `index.html` 一并提交，修改源码后请重新运行构建。发布到静态站点时，访问路径为 `daily-menu/`。
